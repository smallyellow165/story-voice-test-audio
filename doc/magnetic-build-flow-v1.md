# Build 教程 UI 与交互流程 V1

## 操作与来源

普通进入 Build 显示当前 Assembly 预览。按 Assembly ID、revision 及完整内容精确匹配教程，匹配时显示「继续当前教程」，否则显示「生成搭建步骤」。不以全局 `activeId`、同名作品或最近播放记录自动打开教程。

历史列表同时包含已保存教程与未保存预览，标明作品名称、短 ID、版本、步数和保存状态；必须主动选择并打开。播放时固定显示实际教程的作品来源，与所选作品不同时明确标记。作品编辑不会改写教程中的来源快照。

生成／打开 → 播放 → 完成本次播放 → 保存。播放时主入口改为「查看当前作品预览」。完成只更新播放进度；可回看、重播、重新开始或保存，不自动生成、保存或跳转。

## 稳定布局

右栏依次显示来源选择、打开／生成入口、播放来源、当前步骤说明、播放控制、保存与导入导出／历史。说明区域固定高度（随视口高度在 88–140 px 内调整），长文本在内部滚动，每次换步重置内部滚动位置。来源和步骤标题也保留固定高度。

控制区固定为两列两行，每格 42 px：上一步／下一步（最后一步原位替换为完成搭建），重播当前步／重新开始。不会因说明行数、完成文案而改变位置。保存按钮紧接控制区，显示「未保存」或「已保存 · 与保存版本一致」，已保存相同内容禁用重复保存。不同内容的同 ID 导入仍由原来的不可变性校验拒绝。

## 存储与恢复

继续使用 `magnetic-tiles.build.v1` 和现有 Build 校验、保存、Hash、导入导出。原 schemaVersion=1 存档可直接读取；增加可选 `retainedPreviews` 保存被新预览替代的未保存教程及其原进度，不把它们自动标成已保存。最多保留 50 个旧预览，达到上限明确报错并保留原存档，不静默删除。原有最多 50 个已保存方案的规则不变。

- 明确的 Build URL `buildId` 恢复该教程及其自己的进度，允许与当前 Assembly 不同，并显示来源差异。
- 普通 Workflow 导航进入 Build 返回当前作品预览，再由用户生成或继续精确匹配的教程。
- 切换作品、作品版本或图片上下文退出旧播放视图，保留旧教程／进度；不修改 Assembly、Review 或服务器 Selected。
- URL 恢复等待正在执行的保存完成，过期异步操作不能重新打开已离开的教程。原有 Assembly URL 草稿备份机制不变。

存储仍是项目既有的浏览器本地教程库。新标签页可在同一浏览器／站点读取；URL 不包含教程数据，跨浏览器需先导入 JSON。没有增加服务器教程库或并发同步系统。

## 文件

- `BuildPanel.tsx`：当前作品匹配、显式历史打开、上下文／异步恢复保护、连续操作与保存反馈。
- `BuildPlayer.tsx`、`style.css`：固定说明和按钮布局、播放器与 Inspector 的独立插槽。
- `build-context.ts`：精确来源匹配、历史列表、保存内容比较。
- `build-storage.ts`：兼容旧存档的未保存预览保留。
- `main.tsx`、`intake/ImageIntake.tsx`：向 Build 提供已恢复的图片上下文变化通知，不改变识别逻辑。
- `test/magnetic-build-flow.test.mjs`、`scripts/verify-magnetic-build-flow.mjs`：来源隔离、旧进度、9 步小猫、长短文本、完成／保存、刷新／URL／新标签页、窄栏／拖拽／缩放验收。
- 既有浏览器脚本仅更新「继续当前教程」及显式打开历史的交互断言；`package.json` 增加新测试命令。

Build Plan 生成、Geometry Validator、Reconstruction、Profile Registry 和连接规则均未修改。

## 手动验收

1. 在作品编辑中打开现有小猫，进入 Build：先看到当前 9 块作品预览；没有对应教程时生成，有对应教程时点击继续。
2. 连续点击下一步到第 9 步，观察四个控制按钮始终占据原位。拖窄右栏、缩放页面，再切换步骤；长说明只在说明区内滚动。
3. 点击完成搭建，确认仍停在播放器；保存就在下方。未保存教程保存后变为「已保存 · 与保存版本一致」，按钮禁用。
4. 重启／上一步／重播，确认可以继续查看，不会重新生成教程。
5. 切换不同作品或修改作品版本后返回 Build，确认先显示当前预览，不自动进入上一个教程；从历史主动打开时核对固定来源提示。
6. 刷新、复制包含 buildId 的 URL 到同浏览器新标签页、Back／Forward，核对教程及进度。更换图片来源确认退出旧播放，旧历史仍存在。
